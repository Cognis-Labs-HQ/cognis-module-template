# モジュールテンプレート

独自のデータと画面を持つ Cognis 拡張を作るための、インストール可能な見本です。

## できること

見本のページを開き、項目を追加して保存された一覧を確認できます。開発者はこの例を基に独自のモジュールを作れます。

## 始める前に

管理者によるインストールと有効化が必要です。見本のページを開く前にログインしてください。

## はじめに

/showcase を開き、項目名を入力してフォームを送信します。一覧を開き直して保存結果を確認します。

手順は[使用例](USAGE.ja.md)、契約と設定は[技術情報](TECHNICAL.ja.md)を参照してください。
