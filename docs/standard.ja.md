# Cognis 外部モジュールテンプレート

Cognis 外部モジュールテンプレートは、API、UI、CLI、永続化、Capability、フロー、ローカライズ、テスト、パッケージ契約のためのインストール可能な参照実装です。

## 使用例

- モジュールを有効にした後で `/showcase` を開き、ローカライズされたブラウザー画面を使用します。
- `cognisctl module-template:list` を実行し、CLI から同じ認証済み API を使用します。
- `ctx` を通じて `showcase:listItems` Capability を解決し、モジュール内部をインポートせずに項目を一覧表示します。
- `showcase-items` フローを拡張し、名前付きで削除可能な統合ステージから結果を補強します。

## 技術仕様

このテンプレートは、すべての独立した Cognis 外部モジュールが維持すべき境界を示します。

### 統合契約

- `bootstrap.js` はプラットフォーム統合に使用する唯一のエントリポイントです。
- `ctx` はルート、UI 登録、Capability、フロー、認証、ログ、永続化アクセスを提供します。
- ランタイムインポートはリポジトリ相対に限定し、Cognis 内部や他のコンポーネントへアクセスしません。
- スコープ付き登録は、モジュールの無効化またはアンインストール時に削除できなければなりません。

### セキュリティ

- API ルートはビジネスロジックを実行する前に認証と認可を行います。
- リクエストデータは HTTP 境界で制限、検証、正規化されます。
- 公開エラーは内部実装の詳細を公開しません。
- 失敗は安全な構造化メタデータとともに記録されます。

### リリース手順

- `manifest.json`、`package.json`、`package-lock.json` のバージョンを同期し、モジュール UUID を維持します。
- リリースをコミットする前に、`npm install`、`npm test`、`npm run lint`、`npm run manifest:hashes`、`npm run check:manifest`、`git diff --check` を実行します。
- 最後の配布ファイル変更後に `manifest.files` を再生成し、すべてのリポジトリ相対パスと SHA-256 ダイジェストを検証可能にします。
