# 外部モジュールの変更履歴ガイダンスを統一

**機能ブランチ:** feature-align-changelog-structure-with-pr-187

## ローカライズされた変更履歴構造を標準化

外部モジュールのプルリクエスト変更履歴を共有ディレクトリに置き、対応言語ごとにローカライズされたファイルを用意するようになりました。各項目には機能ブランチ、明確な変更見出し、詳しい説明、リンク付きのコミット来歴が含まれるため、Cognis が一貫して検出して表示できます。

## AI コントリビューション手順を統一

コーディングエージェントと GitHub Copilot 向けのリポジトリ手順で、変更履歴の命名、ローカライズ、構造、不変性、来歴に関する同じ要件を説明するようになりました。
