# Changelog-Vorgaben für externe Module vereinheitlichen

**Feature-Zweig:** feature-align-changelog-structure-with-pr-187

## Einheitliche lokalisierte Changelog-Struktur

Externe Module führen Pull-Request-Changelogs nun in einem gemeinsamen Verzeichnis mit einer lokalisierten Datei pro unterstützter Sprache. Jeder Eintrag enthält einen Feature-Zweig, gezielte Änderungsüberschriften, Erläuterungen und verlinkte Commit-Herkunft, damit Cognis ihn einheitlich erkennen und darstellen kann.

## Abgestimmte Anweisungen für KI-Beiträge

Die Repository-Anweisungen für Coding-Agenten und GitHub Copilot beschreiben nun dieselben Vorgaben für Benennung, Lokalisierung, Struktur, Unveränderlichkeit und Herkunft von Changelogs.
