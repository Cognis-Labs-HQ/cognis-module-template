# Menyelaraskan panduan changelog modul eksternal

**Cabang Fitur:** work

## Struktur changelog terlokalisasi yang baku

Modul eksternal kini menyimpan changelog pull request dalam direktori bersama dengan satu berkas terlokalisasi untuk setiap bahasa yang didukung. Setiap entri memuat cabang fitur, judul perubahan yang terarah, penjelasan, dan asal commit bertaut agar Cognis dapat menemukan serta menampilkannya secara konsisten.

## Instruksi kontribusi AI yang selaras

Instruksi repositori untuk agen pemrograman dan GitHub Copilot kini menjelaskan persyaratan penamaan, pelokalan, struktur, sifat tetap, dan asal changelog yang sama.
