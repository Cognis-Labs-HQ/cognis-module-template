# Align external module changelog guidance

**Feature Branch:** feature-align-changelog-structure-with-pr-187

## Standardized localized changelog structure

External modules now keep pull-request changelogs in a shared directory with one localized file per supported language. Each entry includes a feature branch, focused change headings, explanatory details, and linked commit provenance so Cognis can discover and render it consistently.

## Aligned AI contribution instructions

The repository instructions for coding agents and GitHub Copilot now describe the same changelog naming, localization, structure, immutability, and provenance requirements.
